# NA2 Study 학습 대시보드

네트워크관리사 2급 이론·필기·실기 학습을 위한 독립형 브라우저 앱입니다.

## 기능
- 이론 / 필기 / 실기 학습 체크리스트
- 예제 문제 풀이와 정답·해설 피드백
- 마지막 답이 오답인 문항을 모으는 오답노트
- 학습 체크율, 누적 정답률, 영역별 정답률 및 최근 7일 그래프
- 브라우저 localStorage 자동 저장
- JSON 백업 및 복원

## 실행
index.html을 브라우저에서 열면 실행됩니다. 별도 설치나 서버가 필요하지 않습니다.

## 기록 및 데이터 범위
- 학습 기록은 현재 브라우저의 localStorage에 저장됩니다.
- 브라우저/기기 간 자동 동기화는 제공하지 않습니다.
- 초기 버전에는 기능 확인용 예제 문항 9개가 포함되어 있습니다. 원본 NA2-study 저장소의 전체 문제은행과 자동 통합된 것은 아닙니다.
- JSON 백업을 주기적으로 내려받아 보관할 수 있습니다.

## GitHub Pages
.github/workflows/pages.yml 워크플로가 main 브랜치 변경 시 정적 사이트를 배포합니다. 저장소의 Settings → Pages → Build and deployment → Source를 GitHub Actions로 설정해야 합니다.
